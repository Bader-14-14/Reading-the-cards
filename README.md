# مشروع: قراءة البطاقات

وصف مختصر:
تطبيق لالتقاط صور الوثائق (الهوية الوطنية، رخصة القيادة، استمارة السيارة، إقامة) ومعالجة النصوص (OCR) وتصدير النتائج إلى Word أو Excel.

الخطوات التالية:
- تنفيذ Backend بـ FastAPI لمعالجة الصور ودمج مزودات OCR.
- واجهة ويب بسيطة لتحميل الصور ومراجعة النتائج قبل الحفظ.

محتوى أولي مُهيأ على سطح المكتب كما طلبت.
